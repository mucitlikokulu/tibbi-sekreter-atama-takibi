# Tıbbi Sekreter Atama Takip

Sağlık Bakanlığı sözleşmeli Sağlık Teknikeri (Tıbbi Sekreter) KPSS Ön Lisans yerleştirme sonuçları ve kontenjanlarının 81 il için haritalı takibi.

- Veri: ÖSYM / Sağlık Bakanlığı Tablo 2 ve yerleştirme sonuç PDF'leri (2022/5 – 2025/5)
- Resmî bir kaynak değildir; kesin bilgi için ÖSYM ve Sağlık Bakanlığı duyurularına bakın.
- **Yapay Zeka Destekli Tercih Sihirbazı:** puanınıza göre 30 tercihlik (iddialı / hedef / güvenli / garanti) gerçekçi liste ve kurum bazlı yerleşme ihtimali üretir. Tahmin modeli cihazda çalışır; geçmiş dönemlerin kurum bazlı taban puanlarından, dönem seviyesi ve kadro açılma sıklığını da hesaba katarak öğrenir. Yeni dönem verisi eklendiğinde otomatik yeniden hesaplanır. Tahminler resmî değildir.
- Web: GitHub Pages (Settings > Pages > main / root).
- Android APK: GitHub > Actions > "APK Derle" > Run workflow > Artifacts > `Atama-Takip-APK`.
